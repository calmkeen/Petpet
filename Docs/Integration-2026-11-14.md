## 현재 기능 범위

- 꾸미기는 동일한 펫의 외형 선택이다. 눈여우 1종과 배경 자동/새벽/낮/노을/밤, 쉬기/인사/달리기 미리보기를 제공한다. 성장·먹이·걸음 기록을 초기화하지 않는다.
- 꾸미기 편집은 워치에서 하며, 선택은 환경별 로컬 파일에 저장하고 기존 표시용 스냅샷으로 아이폰에 전달한다. 서버 백업·해금·구매·캐릭터별 별도 육성은 포함하지 않는다.
- 별계단 정답은 입력 방향의 1번 프레임 80ms, 2번 100ms를 재생한다. 오답·시간 초과는 마지막 목숨을 포함해 실패 이벤트를 처리하며 중복 소비·반응을 막는다.
- 미니게임 전용 플레이어 아트와 서버 대표 이미지는 꾸미기 선택과 별도다. 이번 통합이 새 캐릭터 리소스나 운영 로그인 서버를 추가한 것은 아니다.

## 공유할 문서

시작점은 [Android·iOS 개발 공유 안내](Collaboration/README.md)다. [선행 개발 인계](Collaboration/FeatureHandoff.md)는 현재 develop에 포함된 꾸미기를 사례로 설명하고, [기능 공유 양식](Collaboration/FeatureTemplate.md)은 이후 기능마다 재사용한다. [꾸미기 상세](PetCustomization.md), [별계단 변경](StarStairFeedback-2026-11-14.md)에서 각각 구현 경계를 확인한다.

이전 기능별 검증 JSON은 당시 브랜치 기준의 증거로 보존한다. 현재 통합 상태와 확인 범위는 이 통합 기록을 따른다.

## 확인 범위

사용자 요청대로 시뮬레이터 대상 **빌드까지만** 확인한다. 공용 모듈·테스트 타깃은 `swift build --build-tests`로 컴파일하고, 아이폰과 내장 워치 앱은 Debug/Release generic iOS Simulator로 빌드한다. 테스트 실행·시뮬레이터 부팅·앱 설치/실행·실제 기기 조작은 수행하지 않는다.

빌드 로그는 `/private/tmp/petpet-two-features-core-build.log`, `/private/tmp/petpet-two-features-integration-build/`에 둔다. 새 기능의 UI·동기화·실제 햅틱 실행 검토는 별도 요청 단계다.

최종 확인 결과는 공용 모듈·테스트 타깃 컴파일과 아이폰/내장 워치 Debug·Release 빌드 모두 성공이다. 실행한 테스트는 **0개**이며 시뮬레이터나 실제 기기를 실행하지 않았다. [코드·머지·빌드 검증 기록](Verification/Integration-2026-11-14.json).
